# OMNIMATRIX - 9 key Macropad

Omnimatrix is a compact and a beginner friendly Macropad which is easy to use as well as easy to build. It is designed by me using a custom PCB and powered by the XIAO RP2040 controller, running KMK firmware (Python Based). This macropad uses a 3x3 matrix with diodes to ensure accurate key detection.
 
# Hardware Components
 • Microcontroller 
 • Mechanical Switches (x9)
 • Custom PCB
 • Diodes
 • Pin-headers

# Key Map
 Key 1:  Undo
 Key 2: Redo
 Key 3: Screenshot
 Key 4: Zoom In
 Key 5: Split
 Key 6: Cut
 Key 7: Copy
 Key 8: Paste
 Key 9: App Switch
