# Omnimatrix
Once my friend told me about hackclub, as I was fascinated by the techinical world, I immediately joined hackclub. I learned Kicad, basic coding and other stuff. Then I attended an event of Hackclub, **Build Guild Delhi**. I explored various unique projects of different Hackclubbers, I was mesmerised by different project and also learned to build Macropad. Then, I started working on it. Firstly, I learned Kicad. I made many mistakes and took many learnings from them. Then finally, I started this project, Omnimatrix. One of the major reason to build this macropad is that, I love to edit videos, and also learning aminations. Editing consistently requires shortcuts like Copy, Paste, Split, Cut, etc. I wanted to simplify editing so, I planned to design it, I spent approx 2 hours on Schematic, 3-4 hours on PCB and 4-5 hours on Case and editing stuff. Also I took help from AI in order to edit the code because currently I don't have much experience in coding. In this project, I used XIAO RP2040-DIP, Mechanical keys (9x) and 1N4148 Diode (9x) etc. for my project. Initially I was confused and made many mistakes. But eventually I build my understanding and corrected those mistakes. It took more than 8 hours to make this project and also spent weeks to learn Kicad, Case designing stuff. After many failures and learnings, **Omnimatrix** a beginner friendly macropad which is easy to use as well as easy to build is finally completed.
